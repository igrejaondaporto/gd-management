# Saúde do GD

![Saúde do GD no fundo da página do GD](imagens/gd-pagina.png)

A **Saúde do GD** é a tua avaliação de como um grupo está. **Só supervisores e pastores** a veem e
escrevem — os líderes não veem esta secção.

## Onde está

- **Na página do GD** (supervisor/pastor): em baixo dos números, na secção **Saúde do GD**.
- **No Painel**: na secção com o mesmo nome, com todos os GDs de uma vez.

## Avaliar um GD

Na página do GD, toca em **Definir** (ou **Atualizar**, se já houver avaliação).

Escolhe uma das três:

| | |
| --- | --- |
| 🟢 **Bom** | O grupo está bem. |
| 🟠 **Atenção** | Há algo a acompanhar. |
| 🔴 **Ruim** | Precisa de intervenção. |

Escreve um comentário — é aqui que o valor está, porque a cor sozinha não diz *porquê*. Depois toca
em **Guardar estado**.

## O histórico

Cada avaliação que escreves **fica guardada para sempre**. A mais recente é o estado atual; todas as
anteriores aparecem em **Histórico**, por baixo, com a data, quem escreveu e o comentário.

O histórico **não se apaga e não se reescreve**. Se uma avaliação antiga estava errada, escreve uma
nova a dizer o que mudou — é isso que torna o histórico útil.

## Corrigir um erro de escrita

Se te enganaste a escrever — uma gralha, uma frase cortada — **não escrevas uma avaliação nova só por
isso**. Toca em **Editar**, no cartão do estado atual, corrige o texto e guarda.

Só podes editar **a avaliação mais recente**, e só **se foste tu que a escreveste**. Assim que
escreveres uma nova, a anterior fica fechada. A entrada editada passa a mostrar **· editado**, para
toda a gente saber que foi corrigida.

## No painel

As linhas aparecem ordenadas **do pior para o melhor** — Ruim, Atenção, Bom, e por fim os que ainda
não têm avaliação. É para que os grupos que precisam de atenção estejam no topo.

Toca numa linha para ver o comentário completo e o histórico. **No painel é só leitura** — para
avaliar, vai à página do GD.
